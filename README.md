# Futures_pricing

Python script for theoretical futures/forwards price modelling using S&P 500 data, Treasury yield curve data  and financial formulas.

**Method**

Using Pandas, Numpy and Matplotlib: <br>
Clean and join/merge data using Pandas. <br>
Process Yield curve data process maturities. <br>
Using continous compounding estimate the forward price. <br>
Automate the construction of maturity-specific forward prices.

**Graphs**

For all times series data and maturities, tables and visualisations were generated.
